# React Tours App

A React application that fetches tour data from an external API and displays interactive tour cards.

## Features
- Fetch tours from API
- Show More / Show Less description
- Remove tours dynamically
- Refresh tours list
- Loading state handling

## Tech Stack
React, JavaScript, CSS Modules, Fetch API

## Concepts Used
- useState
- useEffect
- Conditional Rendering
- Component-based architecture
